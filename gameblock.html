Web Filter
学習用 iPad のブラウザゲームを止める

学校から配られた iPad で、ブラウザから遊べるゲームサイトを 51 件 まとめて遮断する設定ファイルです。アプリのインストールは不要で、iPhone / iPad の標準機能だけで動きます。

無料です。PlayLock を使っていなくても構いません。

この iPad / iPhone に入れる

ほかの端末で入れる場合は、この QR をカメラで読んでください

できること・できないこと

  • できる — 一覧のサイトを、Safari でも Chrome でも開けなくする
  • できる — 成人向けサイトの自動フィルタも同時に有効になる
  • できない — 一覧に無い新しいゲームサイトは止まりません
  • できない — アプリとして入っているゲームは止まりません

学校から借りている端末の場合は、先に確認してください。 「保護者が設定を追加してよいか」は学校ごとに決まりがあります。配布時の書類か、担任の先生にご確認ください。

入れかた

  1. 上のボタン（または QR）から、ファイルを受け取る
  2. 設定アプリを開くと、上の方に「プロファイルがダウンロードされました」と出る
  3. タップ → インストール → 端末のパスコード → もう一度 インストール
  4. Safari で poki.com を開いて、止まることを確認する

やめかた

設定 → 一般 → VPN とデバイス管理 から、 「Web Filter」を選んで削除してください。いつでも元に戻せます。

お子さま自身も、同じ手順で削除できます。 端末のパスコードを知っていれば外せるため、これだけで完全に防げるわけではありません。 あわせて 設定 → スクリーンタイム でスクリーンタイム・パスコードを設定し、 ときどき残っているかを確認してください。

学校の先生・ICT ご担当の方へ

学校の MDM やフィルタリングに取り込んでいただくための形で、同じ内容を用意しています。 端末にインストールする必要はありません。

構成プロファイル（.mobileconfig） MDM にカスタムプロファイルとして取り込む用。com.apple.webcontent-filter（BuiltIn）。 テキストエディタで中身を確認できます ドメイン一覧（テキスト・51 行） フィルタリングの管理画面に貼り付ける用。1 行 1 ドメイン URL 一覧（テキスト） URL 単位でしか登録できない製品用。http / https と www の有無を展開済み

家庭で確かめた結果

保護者が学習用 iPad（iPadOS 26.5）で実際に確認した内容です。

  • 遮断は効きます — 一覧のサイトが Safari・Chrome とも開けなくなりました。学習用サイトへの影響はありませんでした
  • 一括導入はできません — MDM を通さない場合、1 台ずつ画面での承認操作が必要でした（パソコンから自動で入れることはできません）
  • 児童生徒が削除できます — 手作業で入れた設定は、端末のパスコードを知っていれば自分で外せます

このため、学校全体で確実に適用するには MDM からの配信が必要と考えております。

ご注意いただきたい点

  • 学習に必要なサイト（Google 検索・Workspace・Microsoft 365・学習アプリ等）は含めていません
  • xbox.com はゲームが動くのが xbox.com/play です。全面遮断が支障となる場合は、このパスのみのご指定でも結構です
  • フィルタリング製品に「ゲーム」の分類遮断があれば、そちらの方が確実です。この一覧は、分類をすり抜ける回避系サイトの補完としてお使いください
