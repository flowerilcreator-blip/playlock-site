Web Filter
学習用 iPad のブラウザゲームを止める

学校から配られた iPad で、ブラウザから遊べるゲームサイトを 51 件 まとめて遮断する設定ファイルです。アプリのインストールは不要で、iPhone / iPad の標準機能だけで動きます。

無料です。PlayLock を使っていなくても構いません。

この iPad / iPhone に入れる

ほかの端末で入れる場合は、この QR をカメラで読んでください

できること・できないこと

  • できる — 一覧のサイトを、Safari でも Chrome でも開けなくする
  • できる — 成人向けサイトの自動フィルタも同時に有効になる
  • できない — 一覧に無い新しいゲームサイトは止まりません
  • できない — アプリとして入っているゲームは止まりません

学校から借りている端末の場合は、先に確認してください。 「保護者が設定を追加してよいか」は学校ごとに決まりがあります。配布時の書類か、担任の先生にご確認ください。

入れかた

  1. 上のボタン（または QR）から、ファイルを受け取る
  2. 設定アプリを開くと、上の方に「プロファイルがダウンロードされました」と出る
  3. タップ → インストール → 端末のパスコード → もう一度 インストール
  4. Safari で poki.com を開いて、止まることを確認する

やめかた

設定 → 一般 → VPN とデバイス管理 から、 「Web Filter」を選んで削除してください。いつでも元に戻せます。

お子さま自身も、同じ手順で削除できます。 端末のパスコードを知っていれば外せるため、これだけで完全に防げるわけではありません。 あわせて 設定 → スクリーンタイム でスクリーンタイム・パスコードを設定し、 ときどき残っているかを確認してください。
