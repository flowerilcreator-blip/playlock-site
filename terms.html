PlayLock - プレイロック 利用規約

最終更新日: 2026年8月26日バージョン: 1.0

第1条(適用)

本規約は、PlayLock - プレイロック(以下「本アプリ」)の利用条件を定めるものです。本アプリを利用される方(以下「利用者」)は、本規約に同意したうえでご利用ください。

第2条(本アプリの内容)

1. 本アプリは、保護者がお子さまのスマートフォンの利用を管理し、

位置情報を確認することを補助するアプリです。

2. 本アプリは、Apple が提供する公式の Screen Time API を用いて動作します。

端末を遠隔管理する仕組み(MDM)は使用していません。

第3条(利用資格)

1. 本アプリの保護者用機能は、お子さまの親権者または法定の監護者が利用するものです。

2. お子さまの情報を取得することについて、保護者は本アプリの利用開始時に同意する必要があります。

3. 13歳未満のお子さまの情報を取得する場合、保護者の同意が必須です。

第4条(禁止事項)

利用者は、次の行為を行ってはなりません。

1. 本人の同意を得ずに、親権の対象でない者の端末を管理する目的で利用すること

2. 成人の行動を本人の同意なく監視する目的で利用すること

3. 本アプリを解析、改変、リバースエンジニアリングすること

4. 本アプリの動作を妨害する行為

5. 法令または公序良俗に反する行為

第5条(保護者の責任)

1. どのような制限を設定するかは、保護者の判断と責任において行われます。

2. お子さまへの説明および合意の形成は、保護者の責任において行うものとします。

本アプリはそのための情報提供(お子さまの端末での共有内容の表示など)を行いますが、 合意そのものを代替するものではありません。

3. 保護者は、設定内容が適切であるかを定期的に確認するものとします。

第6条(制限機能の限界)

1. 本アプリは、お子さまによるすべての回避行為を防ぐことを保証するものではありません。

次のような場合、制限が働かなくなることがあります。

  • お子さまがアプリを削除した場合
  • 端末の設定からスクリーンタイムの許可が取り消された場合
  • 端末が初期化された場合
  • 本アプリが管理していない別の端末を使用した場合

2. 本アプリは、上記のような状態を検知した際に保護者へお知らせするよう努めますが、

検知および通知の到達を保証するものではありません。

3. 制限の適用は Apple が提供する API の動作に依存します。

OS の仕様変更により、動作が変わる場合があります。

第7条(安全に関する免責)

1. 本アプリの位置情報表示機能は、お子さまの安全を保証するものではありません。

位置情報は端末の状態、電波状況、設定により取得できない場合があります。

2. 緊急時には、本アプリに依存せず、電話その他の適切な手段をご利用ください。

3. 本アプリは、お子さまの安全確保を目的とした監視サービスではありません。

第8条(個人情報の取り扱い)

個人情報の取り扱いについては、別途定めるプライバシーポリシーによるものとします。

第9条(サービスの変更・中断・終了)

1. 提供者は、本アプリの内容を変更し、または提供を終了することがあります。

2. サービスを終了する場合、可能な限り事前にアプリ内またはその他の方法で告知します。

3. 次の場合、事前の告知なくサービスを中断することがあります。

  • システムの保守または障害への対応が必要な場合
  • 天災その他の不可抗力によりサービスの提供が困難な場合

第10条(免責事項)

1. 提供者は、本アプリの利用によって生じた損害について、

提供者に故意または重大な過失がある場合を除き、責任を負いません。

2. 前項の規定は、消費者契約法その他の強行法規に反する範囲では適用されません。

3. 本アプリが依存する外部サービス(Apple の提供する API、通信事業者のネットワーク等)に

起因する不具合について、提供者は責任を負いません。

第11条(規約の変更)

1. 提供者は、本規約を変更することがあります。

2. 重要な変更を行う場合は、アプリ内で通知し、改めて同意をお願いします。

第12条(準拠法および管轄)

1. 本規約は日本法に準拠します。

2. 本アプリに関して紛争が生じた場合、提供者の所在地を管轄する裁判所を

第一審の専属的合意管轄裁判所とします。
